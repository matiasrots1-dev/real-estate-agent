# mcp-weather

MCP server que expone `get_forecast(lat, lng, date)` contra
OpenWeatherMap o WeatherAPI.com (definir cuál en `.env`, ver
`WEATHER_API_PROVIDER`).

**Empezar por acá** (ver `docs/TASKS.md` bloque 2) — es el más simple del
proyecto y sirve para fijar el patrón de MCP server (estructura de
`src/index.ts`, cómo se declara un tool, cómo se testea de forma aislada)
antes de meterse con Tokko o Calendar.
