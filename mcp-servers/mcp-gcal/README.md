# mcp-gcal

MCP server que expone las operaciones de Google Calendar que necesita el
agente: `freebusy`, `create_event`, `patch_event`, `delete_event`,
`list_events`.

No lo escribas desde cero: hay servers MCP de referencia públicos para
Google Calendar. Partí de uno existente y adaptalo a estas funciones y a
las reglas de negocio del proyecto (ver `docs/SOW.md` sección 4.3).
